
# 🍽️ Recipe Application

## 📌 About the Project

Recipe Application is a simple and interactive web application that helps users explore different recipes and learn cooking instructions.

The application provides an easy-to-use interface for discovering recipes and making the cooking experience more convenient.

## ✨ Features

- Explore different recipes.
- View recipe details and cooking instructions.
- Interactive and user-friendly interface.
- Responsive design.
- Easy navigation.

## 🛠️ Technologies Used

- React.js
- TypeScript
- Vite
- Tailwind CSS
- Lucide React
- Motion

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/248x1a05p0-oss/Recipe-application.git
```

### 2. Navigate to the Project

```bash
cd Recipe-application
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

Visit:

[http://localhost:3000](https://recipe-application-o8pn01bh5-recipe-application.vercel.app/)
